# Skills Dashboard

> 一个给 Claude Code 技能库做"可视化档案"的工具 —— 把散落的 SKILL.md 变成一张可以搜索、筛选、展开探索的 HTML 仪表盘。

## 这解决什么问题？

Claude Code 的技能越装越多，到最后自己都记不清有哪些。打开 `.claude/skills/` 目录，几十个文件夹，哪个是干嘛的？什么时候触发？能解决什么问题？

这个项目做一件事：**把全部技能扫一遍，生成一张暖色笔记本风格的 HTML 页面**，每个技能一张可展开的卡片，7 个维度说清楚 —— 从"我是谁"到"产出能不能用"。

## 效果预览

打开 `skills-dashboard.html` 后是一个 3 个 Tab 的页面：

| Tab | 内容 |
|-----|------|
| 我的技能库 | 卡片网格，搜索/分类筛选，点击展开查看 7 维度详情 |
| 什么是 Skill？ | 7 维度框架教学 + brand-guidelines 源码逐行解读 + 填空模板 |
| 技能教程 | 3 种加载方法 + 7 步创建新技能清单 |

暖色笔记本主题 —— 米色纸、格线底纹、衬线标题，不搞"AI 塑料感"。

## 7 维度分析框架

这套框架是我在打磨这个项目的过程中总结出来的。每个合格的 SKILL.md 都应该回答 7 个问题：

| # | 维度 | 问什么 |
|---|------|--------|
| 1 | 元数据 | 我是谁？什么时候触发？ |
| 2 | 边界 | 管什么？不管什么？ |
| 3 | 流程 | 分几步？每步输入→输出→决策？ |
| 4 | 工具 | 靠什么干活？精确到文件名、色值、命令？ |
| 5 | 容错 | 失败了怎么办？有 B 方案吗？ |
| 6 | 评测 | 怎么证明做好了？能写成是/非题吗？ |
| 7 | 验证 | 产出在真实环境里能用吗？ |

维度 1-2 定义**身份和边界**，3-5 定义**行为**，6-7 定义**质量门**。缺维度 2 会在不对的场合触发，缺维度 5 碰见意外就默默失败，缺维度 7 产出看起来对但实际不能用。

## 架构：3 个文件 · 零依赖

```
你的项目目录/
├── skills-dashboard.html        ← 在浏览器打开这个
├── generate-skills-data.js      ← Node.js 脚本（零依赖），跑一次就行
└── skills-data.js               ← 脚本自动生成（window.__SKILLS_DATA__ = {...}）
```

`generate-skills-data.js` 是核心引擎：扫描 `~/.claude/skills/`，解析每个 SKILL.md 的 YAML 和 Markdown，应用三层翻译流水线（手写中文 > 短语词典 > 保留英文），输出 `skills-data.js`。HTML 侧零逻辑 —— 纯加载数据、渲染、交互。

## 快速开始

```bash
# 1. 复制模板到你的目录
cp templates/* 你的项目目录/

# 2. 运行数据生成脚本（零依赖，纯 Node.js 内置模块）
node generate-skills-data.js

# 3. 在浏览器打开
open skills-dashboard.html
```

脚本跑完会打印一行统计：`51 个技能, 16 个分类, 3 个来源` —— 看一眼就知道对不对。

## 预填数据

模板脚本里已经预填了三类数据，别人拿到手跑一次就能出全中文仪表盘：

- **ENRICHMENTS**: 19+ 个技能的 7 维度中文描述
- **BUILTIN_SKILLS**: 8 个 Claude Code 系统技能
- **LARK_SKILLS_MAP**: 24 个技能的分类/场景/工具映射
- **PHRASE_DICT**: 50+ 条英文→中文短语词典（自动翻译后备）

如果你有自己独特的中文技能，往 `ENRICHMENTS` 里加一条就行了。

## 迭代过程（元教训）

这个仪表盘本身经历了 8+ 轮迭代才到满意版本。回头看，一上来不可能想清楚所有细节：

1. 6 维度原型 → 2. 中文翻译 → 3. 自动翻译后备 → 4. 第 7 维度分离 → 5. Tab 2 重写 → 6. 维度顺序修正 → 7. 自动刷新机制 → 8. 卡片动画 + 最终打磨

这里面有一个 meta 道理：**做技能仪表盘本身，就是一个技能工程的练习**。生成脚本是引擎，花时间打磨 enrichment 数据和分类逻辑，仪表盘就自动变好。

## 自定义

- **换颜色/风格**：改 HTML 里 `:root` 的 CSS 变量
- **换整个主题**：搭配 `theme-factory` 或 `frontend-design` 技能
- **加新技能的中文描述**：编辑 `generate-skills-data.js` 里的 `ENRICHMENTS`
- **技能变更后**：重跑 `node generate-skills-data.js`，刷新浏览器
